# Contributing

This repository documents an academic project and welcomes improvements to reproducibility, documentation, testing, and future extensions.

## Contribution principles

- Preserve the distinction between original project material and reconstructed/reference material.
- Do not commit secrets, API keys, or private credentials.
- Add raw experimental data when making performance claims.
- Document hardware changes with an updated wiring table or diagram.
- Keep publication-derived statements traceable to the cited source.
